# 550. Game Play Analysis IV
LeetCode: https://leetcode.com/problems/game-play-analysis-iv/ · Medium

## Problem
For each player, find whether they logged in again on the day immediately after their first login. Return the fraction of all players for whom that's true, rounded to 2 decimal places.

**Activity**
| Column | Type | Notes |
|---|---|---|
| player_id | int | part of primary key |
| device_id | int | |
| event_date | date | part of primary key |
| games_played | int | |

**Example**
```
Activity:
1 | 2016-03-01
1 | 2016-03-02
2 | 2017-06-25
3 | 2016-03-02
3 | 2018-07-03

Output: fraction = 0.33
```
Player 1's first login is 2016-03-01 and they returned the very next day, so they count. Player 2 has only one login. Player 3's first login is 2016-03-02 but their next login is 2018-07-03, not the next day. Only 1 of 3 players qualifies, giving 0.33.

## Solution
```python
import pandas as pd

def gameplay_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    first = activity.groupby('player_id')['event_date'].min().reset_index(name='first_date')
    first['next_day'] = first['first_date'] + pd.Timedelta(days=1)

    returned = activity.merge(
        first,
        left_on=['player_id', 'event_date'],
        right_on=['player_id', 'next_day']
    )
    fraction = round(returned['player_id'].nunique() / activity['player_id'].nunique(), 2)
    return pd.DataFrame({'fraction': [fraction]})
```

1. `groupby('player_id')['event_date'].min()` gives each player's first login, same as 511. Adding `pd.Timedelta(days=1)` to it gives the one date that would count as "came back the next day".
2. The merge matches rows of `activity` against that `next_day` on both `player_id` and date. A row only survives if that player has a login on exactly the day after their first one, and since `(player_id, event_date)` is the primary key, at most one such row exists per player. Players who never came back the next day just drop out of the inner merge.
3. `returned['player_id'].nunique()` counts the players who survived, so it is the numerator. `activity['player_id'].nunique()` counts every player, taken from the original table rather than the merged one so the filtering doesn't shrink the denominator.
4. For the example: player 1 is the only match, so 1 / 3 = 0.33.
5. The result is wrapped in a one-row DataFrame with a `fraction` column because LeetCode expects a table, not a bare number.
