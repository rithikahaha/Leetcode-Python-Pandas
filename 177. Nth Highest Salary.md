# 177. Nth Highest Salary
LeetCode: https://leetcode.com/problems/nth-highest-salary/ · Medium

## Problem
Return the Nth highest **distinct** salary from `Employee(id, salary)`, or null if it doesn't exist. N is passed in as an argument. This is the general version of 176 (which is just this problem with N fixed at 2).

**Employee**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| salary | int | |

**Example 1**
```
Employee: (1, 100), (2, 200), (3, 300)
N = 2
Output: getNthHighestSalary(2) = 200
```

**Example 2**
```
Employee: (1, 100)
N = 2
Output: getNthHighestSalary(2) = null   (only one distinct salary exists)
```

## Solution
```python
import pandas as pd

def nth_highest_salary(employee: pd.DataFrame, N: int) -> pd.DataFrame:
    salaries = employee['salary'].drop_duplicates().sort_values(ascending=False)
    nth = salaries.iloc[N - 1] if len(salaries) >= N else None
    return pd.DataFrame({f'getNthHighestSalary({N})': [nth]})
```

This is 176 with `2` swapped out for `N` everywhere. Dedup, then sort descending, so `[100, 200, 200, 300]` becomes `[300, 200, 100]`. `.iloc[N - 1]` grabs the Nth item from that list: the 1st highest sits at index 0, so the Nth highest sits at index N-1. For N=2 that's `iloc[1]`, which is `200`. The guard `len(salaries) >= N` catches the case where fewer than N distinct salaries exist (Example 2 asks for the 2nd but there's only one), returning `None` instead of an out-of-range index error. The output column name has to match `getNthHighestSalary(N)` literally, with N's actual value substituted in, which is what the f-string is doing.

Since Python functions already take arguments natively, there's no SQL-style `CREATE FUNCTION` wrapper needed here, the whole solution just is the function.

**Simpler alternative, avoids the N-1 indexing entirely:** rank the distinct salaries directly, then just filter for the row whose rank equals N.

```python
import pandas as pd

def nth_highest_salary(employee: pd.DataFrame, N: int) -> pd.DataFrame:
    ranked = employee[['salary']].drop_duplicates()
    ranked['salary_rank'] = ranked['salary'].rank(method='dense', ascending=False)
    match = ranked.loc[ranked['salary_rank'] == N, 'salary']
    nth = match.iloc[0] if not match.empty else None
    return pd.DataFrame({f'getNthHighestSalary({N})': [nth]})
```
`.rank(method='dense', ascending=False)` labels the highest salary 1, the next distinct one 2, and so on, the same idea as `DENSE_RANK()` in SQL. That turns "the Nth highest" into literally `salary_rank == N`, so there's no index math to get wrong. For the first example, 300 gets rank 1 and 200 gets rank 2, so N=2 matches the row with 200. If nothing has that rank (fewer than N distinct salaries exist), `match` comes back empty and `nth` falls back to `None`.
