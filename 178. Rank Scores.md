# 178. Rank Scores
LeetCode: https://leetcode.com/problems/rank-scores/ · Medium

## Problem
Rank scores from highest to lowest. Equal scores get the same rank, and ranking must not leave gaps after a tie (two people tied for 1st means the next distinct score is rank 2, not 3).

**Scores**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| score | float | |

**Example**
```
Scores: (1, 3.50), (2, 3.65), (3, 4.00), (4, 3.85), (5, 4.00), (6, 3.65)

Output (ordered by score descending):
score | rank
4.00  | 1
4.00  | 1
3.85  | 2
3.65  | 3
3.65  | 3
3.50  | 4
```
Both 4.00 rows tie for 1st. The next distinct score, 3.85, is rank 2, not 3, since dense ranking doesn't skip a number after a tie.

## Solution
```python
import pandas as pd

def order_scores(scores: pd.DataFrame) -> pd.DataFrame:
    scores['rank'] = scores['score'].rank(method='dense', ascending=False).astype(int)
    return scores[['score', 'rank']].sort_values('rank')
```

1. `.rank(method='dense', ascending=False)` is pandas' built-in dense ranking: tied scores get the same rank, and the next distinct score continues from the next integer with no gap, exactly what the problem wants. It's the same idea as SQL's `DENSE_RANK()`, just a one-line Series method instead of a window function.
2. `ascending=False` ranks the highest score as 1, since by default `.rank()` gives the smallest value rank 1.
3. `.astype(int)` converts the rank from a float to a plain int. `.rank()` always returns floats, since some other tie-breaking methods can produce ranks like 1.5, but `'dense'` never does, so it's safe to cast here.
4. `sort_values('rank')` orders the final table so the highest score comes first, matching the example output order.
