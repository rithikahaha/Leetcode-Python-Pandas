# 578. Get Highest Answer Rate Question
LeetCode: https://leetcode.com/problems/get-highest-answer-rate-question/ · Medium

## Problem
The answer rate of a question is the number of times it was answered divided by the number of times it was shown. Return the id of the question with the highest answer rate, as a column named `survey_log`. If two questions tie, return the one with the smaller `question_id`.

**SurveyLog**
| Column | Type | Notes |
|---|---|---|
| id | int | the user who acted |
| action | enum | `show`, `answer` or `skip` |
| question_id | int | |
| answer_id | int | null unless the action is `answer` |
| q_num | int | position of the question in the session |
| timestamp | int | |

There is no primary key, and duplicate rows are possible.

**Example**
```
SurveyLog:
id | action | question_id | answer_id | q_num | timestamp
5  | show   | 285         | null      | 1     | 123
5  | answer | 285         | 124124    | 1     | 124
5  | show   | 369         | null      | 2     | 125
5  | skip   | 369         | null      | 2     | 126

Output: survey_log = 285
```
Question 285 was shown once and answered once, a rate of 1. Question 369 was shown once and skipped, a rate of 0.

## Solution
```python
import pandas as pd

def get_the_question(survey_log: pd.DataFrame) -> pd.DataFrame:
    rate = survey_log.groupby('question_id')['action'].agg(
        lambda a: (a == 'answer').sum() / (a == 'show').sum()
    )
    return pd.DataFrame({'survey_log': [rate.idxmax()]})
```

1. `groupby('question_id')['action']` hands each question's list of actions to the lambda, one question at a time.
2. Inside the lambda, `(a == 'answer').sum()` counts the answers and `(a == 'show').sum()` counts the shows, because True counts as 1. Dividing gives that question's answer rate: `285 → 1/1 = 1`, `369 → 0/1 = 0`.
3. `groupby` already returns the questions in ascending id order, and `idxmax()` returns the first position holding the maximum. So on a tie it picks the smaller id, which is the tie rule, with no extra sorting.
4. The result is wrapped in a one-row DataFrame and the column is named `survey_log`, because LeetCode checks that exact name.
