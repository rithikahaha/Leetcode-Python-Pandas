# 580. Count Student Number in Departments
LeetCode: https://leetcode.com/problems/count-student-number-in-departments/ · Medium

## Problem
Report each department's name and how many students it has, including departments with no students. Order by student count descending, then by department name ascending.

**Student**
| Column | Type | Notes |
|---|---|---|
| student_id | int | primary key |
| student_name | varchar | |
| gender | varchar | |
| dept_id | int | foreign key to `Department.dept_id` |

**Department**
| Column | Type | Notes |
|---|---|---|
| dept_id | int | primary key |
| dept_name | varchar | |

**Example**
```
Student: (1, Jack, M, 1), (2, Jane, F, 1), (3, Mark, M, 2)
Department: (1, Engineering), (2, Science), (3, Law)

Output:
dept_name   | student_number
Engineering | 2
Science     | 1
Law         | 0
```
Law has no students but still has to appear, with a count of 0.

## Solution
```python
import pandas as pd

def count_students(student: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    merged = department.merge(student, on='dept_id', how='left')
    result = merged.groupby('dept_name')['student_id'].count().reset_index(name='student_number')
    return result.sort_values(['student_number', 'dept_name'], ascending=[False, True])
```

1. Merging with `department` on the left keeps every department. Law has no matching student, so its `student_id` is NaN.
2. `count()` only counts non-null values, so Law gets 0. `size()` would count the row itself and wrongly give Law a 1.
3. `reset_index(name='student_number')` turns the counts back into a table with the right column name.
4. `sort_values` takes one direction per column: count descending, then name ascending.
