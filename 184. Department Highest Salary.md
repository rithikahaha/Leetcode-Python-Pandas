# 184. Department Highest Salary
LeetCode: https://leetcode.com/problems/department-highest-salary/ · Medium

## Problem
Find the employee(s) with the highest salary in each department. Return `Department`, `Employee`, `Salary` for every such employee (ties all count).

**Employee**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| name | varchar | |
| salary | int | |
| departmentId | int | foreign key to `Department.id` |

**Department**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| name | varchar | |

**Example**
```
Employee: (1, Joe, 70000, 1), (2, Jim, 90000, 1), (3, Henry, 80000, 2), (4, Sam, 60000, 2), (5, Max, 90000, 1)
Department: (1, IT), (2, Sales)

Output:
Department | Employee | Salary
IT         | Jim      | 90000
Sales      | Henry    | 80000
IT         | Max      | 90000
```
Jim and Max both earn 90000, IT's highest, so both qualify. Henry earns Sales' highest, 80000. Joe and Sam earn less than their department's top, so they're excluded.

## Solution
```python
import pandas as pd

def department_highest_salary(employee: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    max_salary = employee.groupby('departmentId')['salary'].transform('max')
    top_earners = employee[employee['salary'] == max_salary]

    merged = top_earners.merge(
        department, left_on='departmentId', right_on='id',
        suffixes=('_employee', '_department')
    )
    return merged.rename(columns={
        'name_employee': 'Employee',
        'name_department': 'Department',
        'salary': 'Salary'
    })[['Department', 'Employee', 'Salary']]
```

1. `groupby('departmentId')['salary'].transform('max')` computes each department's highest salary but keeps one row per original employee instead of collapsing into groups, the same `transform` trick used in 512 (Game Play Analysis II). Every IT row gets 90000 attached; every Sales row gets 80000.
2. `employee['salary'] == max_salary` keeps rows where an employee's own salary matches their department's max: Jim and Max pass in IT, Joe doesn't; Henry passes in Sales, Sam doesn't. Ties survive automatically since both tied rows independently satisfy the equality.
3. Merging in `department` attaches the readable department name. `suffixes=('_employee', '_department')` is needed because both tables have a `name` column, and without it the merge would raise a collision instead of picking one silently.
4. The final rename and column selection match LeetCode's expected output names and order.
